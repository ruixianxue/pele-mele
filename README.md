# pêle-mêle

一个把拍立得照片从抽屉里搬到屏幕上的小画廊：上传照片，它们先叠成一叠摆在桌面（床单）中央偏下的位置，点一下画布哗地散开，按住划一划还能把照片推着走。目标是"随手一拍就能美美欣赏"，不需要用户做任何整理排版。

完整产品思路见对话历史里的 PRD；这里只记录代码现状。

## 当前状态

Phase 1 原型：真实上传 + 散落物理交互已经跑通。自动裁切校色、点击详情页、归档入口还没做（见下面「尚未实现」）。

照片目前只存在浏览器内存里（`URL.createObjectURL`），刷新页面就没了——还没接后端/存储。

## 技术栈

- React + TypeScript + Vite
- 无第三方物理库：`src/lib/physics.ts` 是一个手写的轻量 DOM 物理模拟（位置/旋转直接写 `transform`，不走 React state，避免几十张照片跟手划动时掉帧）
- 纯 CSS/SVG 做白色床单质感背景和照片阴影，没有用外部图片素材

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

## 已实现功能

- **真实上传**：拖拽或点击上传，可多选；卡片直接渲染上传的原图，边到边，不额外画 UI 假边框——照片自带的白边就是它的边框
- **散落物理**：点击画布哗地散开（带随机抛掷动量，不是瞬移）；按住划动会把靠近指针的照片推开，力度随划动速度和距离衰减；卡片之间有轻量互斥力，避免完全重叠的死角；"再乱一次"按钮重新给已散开的照片一次随机推力
- **自适应尺寸**：卡片尺寸按照片总数自动缩放（照片少时更大更醒目，照片多时更紧凑），同时保留每张照片各自的真实宽高比，不强行套固定画幅
- **追加上传**：散开状态下继续上传，新照片会从中心弹入现有排布，不会打乱已经摆好的其他照片
- **背景**：白色床单质感——暖白基色、左上方向光、几处低对比度的褶皱阴影、极细腻的棉布噪点纹理

## 项目结构

```
src/
  components/
    Gallery.tsx      主界面：上传入口、手势处理、堆叠/散落状态机
    PhotoCard.tsx     单张照片卡片，注册进物理模拟、渲染真实图片
  lib/
    physics.ts        DOM 物理模拟（位置/旋转/摩擦/互斥/边界反弹）
    formats.ts         按张数和照片真实宽高比计算卡片尺寸
    uploadedPhoto.ts    读取上传文件、生成 object URL
  styles.css          床单背景、卡片阴影、上传 UI 样式
```
